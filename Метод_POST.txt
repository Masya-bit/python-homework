
Название: Создание поста с корректными данными
Тип: Позитивный
Метод: POST
Эндпоинт: /posts
Шаги:
1 - Отправить POST-запрос с телом {"title": "Test", "body": "Hello", "userId": 1}
ОР: Статус-код 201, в ответе есть id, title равен "Test"

Название: Создание поста с некорректными типами данных
Тип: Негативный 
Метод: POST
Эндпоинт: /posts
Шаги:
Отправить POST-запрос с телом {"title": 12345, "body": "Hello", "userId": "не число"}
ОР: Статус-код 201, API принимает запрос, title равен 12345
